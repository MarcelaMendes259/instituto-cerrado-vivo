# Instituto DF Cerrado

Projeto front-end acadêmico de uma ONG fictícia voltada à conservação do Cerrado no Distrito Federal.

## Páginas
- `index.html` — apresentação institucional
- `projetos.html` — projetos, espécies, contribuição e voluntariado
- `cadastro.html` — formulário de cadastro de voluntários

## Tecnologias
HTML5, CSS3 e JavaScript.

## Observação
Projeto fictício desenvolvido exclusivamente para fins acadêmicos. Nenhuma doação ou dado de formulário é processado por um servidor real.
